# Security

This integration talks to the Koolnova cloud API with your account
credentials, so treat it as a security-sensitive project.

If you find a vulnerability, report it privately through **Security → Report
a vulnerability** on this repository
(<https://github.com/luisgsluis/homeassistant-koolnova/security/advisories/new>)
— please don't open a public issue. Include what you found and, if possible,
steps to reproduce.
